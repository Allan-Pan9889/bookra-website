# SEO 优化记录 · 2026-10-08

依据 2026-10-08 整站诊断，完成网站代码层面的修正。用户确认：家庭订阅共 6 人，没有付费试用。

## 已实施

1. 中文 `/`、英文 `/en/` 分别包含静态正文、匹配语言的 title / description / OG、自指 canonical 和互指 hreflang。语言切换改为原生链接，删除 localStorage 改写语言的行为。
2. 正式域名统一为 `https://www.bookra.im`，同步全站 canonical、hreflang、OG、JSON-LD、robots 和 sitemap。
3. 修复 `/terms` 到独立条款页；首页文件名、英文目录和内页别名使用永久跳转。保留英文旧语言参数入口和营销来源参数。
4. 生成 320 / 640 / 960px 响应式 WebP，优化 Logo 和社交图片，补充尺寸；主截图 eager，其余截图 lazy。原始截图保留于仓库，生产仅复制优化后的资源。
5. 浏览器 Tailwind CDN 改为固定版本 Tailwind 4.3.3 构建静态 CSS；本地托管 Inter / Caveat 字体并保留 OFL 许可证；保留现有页面设计，不引入前端应用框架。构建监听依赖固定到兼容的 2.6.0，完整依赖审计无已知漏洞。
6. 删除“数千名读者”、未实现的 SearchAction、任意价格有效期和示例推荐中的“90% 匹配”。保持虚构评分字段已删除的状态。
7. 家庭版统一为总计最多 6 人（含购买者）；免费版统一 30 本书 / 每天 2 次 AI 灵感。修正支持页旧价格，说明地域价格以 App Store 购买页为准。付费订阅明确不含免费试用。
8. 支持页隐私表述与现有隐私政策对齐，明确第三方 AI 处理相关书籍数据，删除绝对“不与第三方共享”和仅在自有服务器处理的承诺。
9. 中文支持页补足到 10 个问题；FAQPage 内容直接对应可见正文。删去无依据的自动学习改善识别、固定分析耗时承诺。
10. 全站补移动菜单和语言链接，首页页脚补价格入口；无 JavaScript 仍可导航。菜单兼容 320px 屏宽，补齐 main 区域与连续标题层级，扩大链接点击区域。
11. sitemap 包含 10 个正式页面，省略无法可靠维护的 lastmod，以及 changefreq / priority。
12. 添加 favicon、Apple 图标、Smart App Banner；中英文下载按钮分别使用含同一真实应用 ID 的中、美区 App Store 链接。
13. 增加 GA4 `app_store_click` 事件，以页面语言与落地路径区分。
14. 补充可复现构建、发布说明与 SEO 回归测试。
